# Third-party notices

FoxHole Guard is distributed under the GNU General Public License v3.0 or later
(see [LICENSE](LICENSE)). It ships and links the third-party work inventoried
below. This file records that work and the attribution or licence information
needed to understand the distributed APK.

The APK also contains `assets/licenses/`, a user-readable bundle of exact
upstream licence and NOTICE files for the bundled native runtimes, native Android
libraries, fonts, icons and flag source set identified below. Settings → About
→ Licenses opens those files in the app. The same checked bundle is attached
to each GitHub release as `FoxHole-v<version>-license-notices.zip`; its
`SHA256SUMS` covers every included file.

For exact Java/Kotlin dependency versions and package URLs, see the CycloneDX
inventory generated by `./gradlew cyclonedxBom -Pfoxhole.sbom=true` and attached
to each release. The current Gradle generator does not populate component
licence fields, so that inventory is not presented as licence-completeness
evidence. The checked files in `assets/licenses/` are the release evidence for
the embedded native libraries and asset sources named above. For the Rust side,
the pinned FoxHole Core SBOM and notices are copied into the licence bundle. Its
`aarch64-linux-android` SBOM currently contains 503 components, each with an
upstream-declared licence expression.

## Tor pluggable transports (built from source)

Built from source staged under
`app/src/main/assets/tor/<abi>/tor/pluggable_transports/`, then packaged as
`lib/<abi>/liblyrebird.so` and `lib/<abi>/libconjure_client.so` so Android can
execute them from the app's native-library directory. Both are compiled from
pinned upstream source by `scripts/build-tor-transports.sh` with a pinned Go
toolchain; no prebuilt transport executable is taken from a third-party bundle.

### lyrebird (obfs4proxy successor)

- Upstream: https://gitlab.torproject.org/tpo/anti-censorship/pluggable-transports/lyrebird
  (pinned at `lyrebird-0.8.1`)
- Licenses: **GPL-3.0-or-later AND BSD-3-Clause**, © Yawning Angel and
  contributors. The pinned source includes GPL-3.0-or-later implementation in
  `transports/meeklite` and `internal/x25519ell2`; both packages are compiled
  into the shipped executable. Exact upstream texts are `LICENSE-GPL3.txt` and
  `LICENSE` in the pinned checkout.
- Statically links 61 Go modules. The generated `tor/GO-MODULES.json` records
  the exact list obtained from the shipped binary, and `tor/go-modules/` carries
  every root or nested `LICENSE`, `COPYING` and `NOTICE` file from those pinned
  module-cache entries, including the AWS SDK and smithy-go notices.

### conjure-client

- Upstream: https://gitlab.torproject.org/tpo/anti-censorship/pluggable-transports/conjure
  (the Tor Project packaging of https://github.com/refraction-networking/conjure,
  pinned by commit in `scripts/build-tor-transports.sh`)
- License: **BSD-3-Clause**, © Refraction Networking
- Statically links 33 Go modules; its complete dependency license set is
  generated from the shipped binary by the same process. The two transports
  use 78 distinct resolved modules in total.
- The public beta APK packages both transports for `arm64-v8a` only. Other ABI
  outputs are development build targets and are not part of the distributed APK.

### Tor Project integration configuration

- `torrc-defaults`, `pt_config.json` and `README.CONJURE.md` are unmodified
  members of the official Tor Project Expert Bundle 15.0.9 for Android aarch64.
- The source archive URL, its SHA-256 and the accepted member hashes are recorded
  in `third_party/tor-config/`. The release generator verifies the equivalent
  files in every bundled ABI directory and copies the evidence into
  `assets/licenses/tor-config/`.
- FoxHole Guard does not package the archive's `libTor.so`, GeoIP databases or
  prebuilt transport executables. The archive supplies only these integration
  files; FoxHole Core supplies Tor and the two transports are rebuilt from the
  pinned source described above.

## Reviewed Conjure STUN migration

The pinned Conjure v0.9.1 dependency uses STUN v3.1.5 for both client import sites.
`scripts/prepare-tor-dependency.py` copies verified module sources into a build
folder and checks the original file hashes before applying this import migration.
The original module identity and licenses remain in the delivery inventory;
the patch script and input hashes are included in the bundled notices.
