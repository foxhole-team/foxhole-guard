## FoxHole Core — the network runtime

Built from source (`scripts/android-build.sh` in the FoxHole Core repository, pinned
by `config/foxcore-revision.txt`) and shipped as `libfoxhole_native.so`.

- License: GPL-3.0-or-later, © 2026 FOXHOLE TEAM
- Statically linked into that `.so` are ~492 Rust crates; their licenses are
  MIT, Apache-2.0, BSD-2/3-Clause, ISC, Unicode-3.0, MPL-2.0 and CC0-1.0. The
  full list with versions and license identifiers is the SBOM named above, which
  CI regenerates and `cargo deny check licenses` gates on both dependency graphs.

Notable components inside it:

### Arti — the Tor client

- Upstream: https://gitlab.torproject.org/tpo/core/arti
- License: **MIT OR Apache-2.0**, © The Tor Project, Inc. and contributors
- This is the Rust Tor implementation FoxHole Core links, **not** the C `tor` daemon.

## Tor pluggable transports (built from source)

Shipped as binaries under `app/src/main/assets/tor/<abi>/tor/pluggable_transports/`
and launched as managed transports for Arti's bridges. Both are compiled from
pinned upstream source by `scripts/build-tor-transports.sh` with a pinned Go
toolchain; no prebuilt transport executable is taken from a third-party bundle.

### lyrebird (obfs4proxy successor)

- Upstream: https://gitlab.torproject.org/tpo/anti-censorship/pluggable-transports/lyrebird
  (pinned at `lyrebird-0.8.1`)
- License: **BSD-3-Clause**, © Yawning Angel and contributors
- Statically links ~50 Go modules (BSD-3-Clause, MIT, Apache-2.0, ISC). The
  Apache-2.0 ones (`aws-sdk-go-v2`, `smithy-go`, `golang/mock`, `tjfoc/gmsm`)
  additionally require their NOTICE text to be reproduced; run
  `go version -m lyrebird` on a shipped binary for the authoritative module list.

### conjure-client

- Upstream: https://gitlab.torproject.org/tpo/anti-censorship/pluggable-transports/conjure
  (the Tor Project packaging of https://github.com/refraction-networking/conjure,
  pinned by commit in `scripts/build-tor-transports.sh`)
- License: **BSD-3-Clause**, © Refraction Networking
- Statically links ~34 Go modules under the same license families as above.
- The public beta APK packages both transports for `arm64-v8a` only. Other ABI
  outputs are development build targets and are not part of the distributed APK.

## Stalkerware indicators — SENTINEL threat intel

- Upstream: https://github.com/AssoEchap/stalkerware-indicators (`ioc.yaml`)
- License: **CC-BY-4.0** — © Echap (https://echap.eu.org) and contributors
- The bundled detector seed `app/src/main/assets/sentinel/threat-intel.json` is
  built from that file by `scripts/build-sentinel-threat-intel.py`; the upstream
  revision and its SHA-256 are recorded in `threat-intel.source.json` next to it.
- Imported: Android package identifiers, signing-certificate fingerprints
  (SHA-256 and SHA-1, kept in separate fields), and the C2/distribution domains
  and IP addresses used by the FoxHole Sentinel network IOC matcher. Not imported: YARA
  rules, APK digests, iOS bundle identifiers and X.509 subject matchers.
