Foxhole - Android-клиент для подключения и управления VPN профилями `sing-box` с поддержкой подписок формата v2raytun и работы в режиме VPN-туннеля, локального прокси, раздельной маршрутизации и опциональной маршрутизации TCP-трафика отдельных приложений через сеть TOR внутри VPN.

Приложение позволяет запускать соединение в режимах VPN-туннеля и локального прокси, настраивать маршрутизацию для приложений и доменов, использовать локальный DNS rule set, а также применять базовые правила ограничения трафика.

Foxhole не содержит рекламы, аналитики и телеметрии.

## Статус

- Текущий публичный выпуск: `public beta 1.0`
- Платформа: Android
- Версии для других платформ пока не планируются

## Основные функции

- VPN-туннель и режим локального прокси
- Split Tunnel для приложений и доменов
- Опциональная маршрутизация TCP-трафика через сеть TOR
- Локальная DNS-фильтрация
- Исключения DNS-фильтрации для приложений и доменов
- LAN Proxy по Wi-Fi
- Авторизация прокси
- Правила маршрутизации по доменам
- Импорт профилей из файла, буфера обмена, QR-кода и HTTPS-подписок
- Foxhole Smart Config для группировки вариантов подключения
- Smart start для локального выбора подходящего варианта подключения
- Локальная статистика трафика
- Отображение срока действия подписки
- Зашифрованное локальное хранение профилей

## Foxhole smart config

Foxhole smart config позволяет одной подписке содержать несколько логических профилей и несколько вариантов протокола внутри каждого профиля.

Например, один профиль может содержать несколько функционально эквивалентных вариантов подключения через разные протоколы или транспорты. Это позволяет держать варианты подключения синхронизированными и выбирать подходящий вариант без ручного переключения каждого отдельного URI.

## Smart start

Smart start автоматически выбирает подходящий вариант подключения из доступных вариантов протокола.

Алгоритм работает локально на устройстве:

- пробует доступные варианты протоколов;
- ранжирует их на основе прошлого опыта и текущей сети;
- сначала пытается рекомендованный вариант;
- подключается через первый успешно прошедший валидацию вариант.

Алгоритм работает последовательно и ограниченно:

- пробует до трёх кандидатов при автоматическом подключении;
- переходит к следующему варианту только при ошибке;
- может проверить все варианты при ручном обновлении метрик.

Со временем система адаптируется:

- запоминает успешные подключения, в том числе для конкретной сети;
- избегает недавно неработающих протоколов;
- учитывает последний рабочий вариант;
- использует отдельную память для разных сетей.

При ранжировании учитываются:

- история успешных и неудачных подключений;
- состояние DNS и сети;
- задержка и время подключения;
- признаки валидного трафика;
- cooldown и недавние сбои.

Из выбора автоматически исключаются:

- отключённые варианты;
- протоколы в cooldown.

Smart start не отправляет разработчику данные о подключениях, конфигурациях, трафике или использовании приложения. Решение принимается на устройстве.

## DNS-фильтрация

Foxhole может использовать локальный DNS rule set для блокировки рекламных, трекерных, телеметрических и потенциально вредоносных доменов.

В приложении есть встроенный DNS фильтр, который использует Adguard DNS. В приложении можно включить обновление фильтра из публичного репозитория Foxhole:

[foxhole-dns](https://github.com/foxhole-repo/foxhole-dns)

Официальный manifest endpoint:

```text
https://foxhole-repo.github.io/foxhole-dns/manifest.json
```

DNS rule set собирается в CI из открытого AdGuard DNS filter, публикуется вместе с manifest-файлом и проверяется приложением по подписи, размеру и SHA-256 перед использованием.

Загружаемый файл является данными DNS-фильтрации для sing-box, а не исполняемым кодом.

Если проверка подписи, размера или контрольной суммы не проходит, Foxhole не использует загруженный файл и продолжает работать со встроенным или последним проверенным фильтром.

Пользователь может отключить DNS-фильтрацию и добавить исключения для отдельных приложений или доменов.


## Маршрутизация через сеть TOR

Foxhole может опционально направлять TCP-трафик через сеть TOR. UDP-трафик через сеть TOR не передаётся.

Если маршрутизация через сеть TOR включена внутри VPN, выбранный TCP-трафик идёт через сеть TOR, а UDP остаётся в обычном VPN-маршруте или блокируется настройками приложения. Если сеть TOR оставлена на маршруте устройства при активном VPN, VPN и сеть TOR работают параллельно. Такой режим может увеличивать расход батареи.


## Разрешения и приватность

Foxhole использует только те разрешения, которые нужны для заявленных функций приложения.

- `INTERNET` - сетевое подключение, загрузка профилей, работа VPN/прокси, проверка подключения, работа выбранного DNS-сервера и опциональное обновление DNS rule set.
- `ACCESS_NETWORK_STATE` и `ACCESS_WIFI_STATE` - определение состояния сети и Wi-Fi для VPN/прокси и LAN Proxy.
- `FOREGROUND_SERVICE` и `FOREGROUND_SERVICE_SPECIAL_USE` - постоянная работа VPN/прокси с видимым уведомлением.
- `QUERY_ALL_PACKAGES` - показ установленных приложений для Split Tunnel, DNS-исключений, локального обзора приложений и опциональной статистики по приложениям.
- `PACKAGE_USAGE_STATS` - запрашивается только при включении статистики трафика по приложениям.
- `CAMERA` - сканирование QR-кодов для импорта профилей.
- `POST_NOTIFICATIONS` - уведомления о состоянии VPN/прокси.
- `RECEIVE_BOOT_COMPLETED` - восстановление пользовательского режима запуска после перезагрузки, если это включено пользователем.
- `WAKE_LOCK` - поддержание активной VPN/прокси-сессии.

Списки установленных пакетов, локальные сигналы риска, статистика, диагностика, история Smart start, пользовательские DNS-исключения и состояние DNS-фильтрации остаются на устройстве, если пользователь сам не экспортирует или не отправит их.

## Сетевые запросы

Foxhole может выполнять сетевые запросы для функций, выбранных пользователем:

- загрузка HTTPS-подписок;
- проверка работоспособности соединения;
- получение информации о текущем IP-адресе через настраиваемый endpoint;
- работа выбранного DNS-сервера;
- опциональная загрузка обновлённого DNS rule set из публичного репозитория Foxhole;
- пользовательский экспорт или передача диагностической информации, если такая функция явно выбрана пользователем.

Foxhole не выполняет рекламную аналитику и не отправляет телеметрию разработчику.

При обновлении DNS-фильтра приложение загружает manifest-файл и DNS rule set. Загруженный rule set используется только после проверки подписи, размера и SHA-256. Foxhole не отправляет разработчику список установленных приложений, пользовательские DNS-исключения, DNS-журнал или статистику фильтрации.
