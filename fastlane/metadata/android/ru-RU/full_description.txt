Foxhole — Android-клиент для подключения и управления профилями sing-box с поддержкой подписок формата v2raytun и работы в режиме VPN-туннеля, локального прокси, раздельной маршрутизации и опциональной маршрутизации TCP-трафика отдельных приложений через сеть TOR внутри VPN.

Приложение позволяет запускать соединение в режимах VPN-туннеля и локального прокси, настраивать раздельную маршрутизацию для приложений и доменов, использовать DNS-фильтрацию, а также применять базовые правила ограничения трафика.

Основные функции:

* VPN-туннель и режим локального прокси
* раздельная маршрутизация для приложений и доменов
* опциональная маршрутизация TCP-трафика через сеть TOR
* локальная DNS-фильтрация
* исключения DNS-фильтрации для приложений и доменов
* LAN-прокси по Wi-Fi
* авторизация прокси
* правила маршрутизации по доменам
* импорт профилей из файла, QR-кода, буфера обмена и HTTPS-подписок
* локальная статистика трафика
* отображение срока действия подписки
* зашифрованное локальное хранение профилей VPN

Поддерживаемые протоколы:

* VLESS
* Trojan
* Shadowsocks
* VMess
* Hysteria2
* WireGuard
* Outline

Smart start выбирает подходящий вариант подключения из доступных вариантов протокола. Выбор основан на локальной истории успешных и неудачных подключений, задержке, состоянии сети и последнем рабочем варианте. Эти данные не отправляются разработчику и не передаются на сторонние серверы.

Сеть TOR:
В приложении есть опциональная маршрутизация TCP-трафика через сеть TOR. UDP-трафик через сеть TOR не передаётся. Если маршрутизация через сеть TOR включена внутри VPN, выбранный TCP-трафик идёт через сеть TOR, а UDP-трафик остаётся на обычном VPN-маршруте или блокируется в зависимости от настроек.

TOR является товарным знаком The TOR Project. Foxhole не является продуктом The TOR Project, не одобрен, не спонсируется и не аффилирован с The TOR Project.

DNS-фильтрация:
Foxhole может использовать локальный DNS rule set для блокировки рекламных, трекерных, телеметрических и потенциально вредоносных доменов. В приложении есть встроенный резервный фильтр. Пользователь может включить обновление фильтра из публичного репозитория Foxhole. Обновлённый rule set собирается в CI из открытого AdGuard DNS filter, публикуется вместе с manifest-файлом и проверяется приложением по подписи, размеру и SHA-256 перед использованием.

Загружаемый файл является данными DNS-фильтрации для sing-box, а не исполняемым кодом. Если проверка подписи или контрольной суммы не проходит, Foxhole не использует загруженный файл и продолжает работать со встроенным или последним проверенным фильтром. Пользователь может отключить DNS-фильтрацию и добавить исключения для приложений или доменов.

Foxhole не является продуктом AdGuard и не аффилирован с AdGuard Software Ltd.

Разрешения и приватность:
QUERY_ALL_PACKAGES используется для выбора приложений, которые включаются или исключаются из VPN/прокси-маршрутизации, настройки DNS-исключений, локального обзора установленных приложений и опциональной статистики трафика по приложениям.

PACKAGE_USAGE_STATS запрашивается только при включении статистики по приложениям. Списки пакетов, локальные сигналы риска, статистика, диагностика, история Smart start, пользовательские DNS-исключения и состояние DNS-фильтрации остаются на устройстве, если пользователь сам не экспортирует или не отправит их.

Сетевые запросы:
Foxhole не содержит рекламы, аналитики и телеметрии. Приложение может выполнять сетевые запросы для функций, которые выбрал пользователь: загрузка HTTPS-подписок, проверка работоспособности соединения, получение информации о текущем IP-адресе через настраиваемый endpoint, работа выбранного DNS-сервера и опциональная загрузка обновлённого DNS rule set из публичного репозитория Foxhole.

Эти запросы нужны для работы VPN/прокси, проверки подключения и выбранных пользователем функций. Foxhole не отправляет разработчику список установленных приложений, пользовательские DNS-исключения, DNS-журнал или статистику DNS-фильтрации.
