Foxhole - простой Android-клиент для подключения и управления профилями sing-box.

Поддерживает режимы Tunnel, Split Tunnel (по приложениям и доменам), Proxy и LAN Proxy, а также импорт профилей из файла, буфера обмена, QR-кода и HTTPS-подписок.

Без рекламы. Без аналитики. Без телеметрии.

Ключевые функции:

* Режимы: Tunnel, Split Tunnel, Proxy
* LAN Proxy по Wi-Fi для доступа с других устройств
* Авторизация прокси
* Правила маршрутизации по доменам
* Импорт: файл, буфер обмена, QR-код, HTTPS-подписки
* Поддержка Foxhole Smart Config и автоматического выбора протокола (Smart start)
* Локальная статистика трафика
* Отображение срока действия подписки
* Зашифрованное локальное хранение профилей

Smart start автоматически выбирает наиболее стабильный протокол, тестируя доступные варианты и используя локальную историю.
При выборе учитываются успешность подключений, задержка и недавние ошибки. Все вычисления выполняются на устройстве.

Примечание о разрешении:
Foxhole использует QUERY_ALL_PACKAGES, чтобы показывать установленные приложения для include/exclude маршрутизации в Split Tunnel, локальной проверки установленных приложений/рисков и опциональной статистики трафика по приложениям. Usage Access (PACKAGE_USAGE_STATS) запрашивается только при включении статистики трафика по приложениям. Список пакетов, локальные сигналы риска, статистика трафика, диагностика и история Smart start остаются на устройстве, если вы явно не экспортируете или не отправите их сами.

Поддерживаемые протоколы:

* VLESS
* Trojan
* Shadowsocks
* VMess
* Hysteria2
* WireGuard
* Outline
