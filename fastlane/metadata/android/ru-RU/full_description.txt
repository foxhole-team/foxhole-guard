Foxhole — Android клиент для подключения и управления профилями sing-box с поддержкой VPN туннеля, локального прокси, раздельной маршрутизации и опциональной маршрутизации TCP трафика отдельных приложений через сеть Tor внутри VPN.

Приложение позволяет запускать соединение в режимах VPN-туннеля и локального прокси, настраивать раздельную маршрутизацию для приложений и доменов, а также использовать базовые правила ограничения трафика.

Основные функции:

* VPN туннель и режим локального прокси
* раздельная маршрутизация для приложений и доменов
* опциональная маршрутизация TCP-трафика через сеть Tor
* LAN-прокси по Wi-Fi
* авторизация прокси
* правила маршрутизации по доменам
* импорт профилей из файла, QR кода, буфера обмена и HTTPS подписок
* локальная статистика трафика
* отображение срока действия подписки
* зашифрованное локальное хранение профилей

Поддерживаемые протоколы:

* VLESS
* Trojan
* Shadowsocks
* VMess
* Hysteria2
* WireGuard
* Outline


Smart start выбирает подходящий вариант подключения из доступных вариантов протокола. Выбор основан на локальной истории успешных и неудачных подключений, задержке, состоянии сети и последнем рабочем варианте. Эти данные не отправляются разработчику и не передаются на сторонние серверы.

Сеть Tor:
В приложении есть опциональная маршрутизация TCP-трафика через сеть Tor. UDP-трафик через сеть Tor не передаётся. Если маршрутизация через сеть Tor включена внутри VPN, выбранный TCP-трафик идёт через сеть Tor, а UDP-трафик остаётся на обычном VPN-маршруте или блокируется в зависимости от настроек.

Tor является товарным знаком The Tor Project. Foxhole не является продуктом The Tor Project, не одобрен, не спонсируется и не аффилирован с The Tor Project.

Разрешения и приватность:
QUERY_ALL_PACKAGES используется для выбора приложений, которые включаются или исключаются из VPN/прокси-маршрутизации, локального обзора установленных приложений и опциональной статистики трафика по приложениям.
PACKAGE_USAGE_STATS запрашивается только при включении статистики по приложениям. Списки пакетов, локальные сигналы риска, статистика, диагностика и история Smart start остаются на устройстве, если пользователь сам не экспортирует или не отправит их.

Сетевые запросы:
Foxhole не содержит рекламы, аналитики и телеметрии. Приложение может выполнять сетевые запросы для функций, которые выбрал пользователь: загрузка HTTPS-подписок, проверка работоспособности соединения и получение информации о текущем IP-адресе через настраиваемый endpoint. Эти запросы нужны для работы VPN/прокси и проверки подключения.
