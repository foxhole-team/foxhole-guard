1.0.0 Stable (кандидат выпуска)

- Уточнены данные выпуска, сохранена история сборок F-Droid.
- Главная в режиме User учитывает выбранный вид карты или маршрута.
- Большая карта видна по умолчанию; управление видимостью терминала остаётся в режиме Expert.
- Чёрно-белый лис без фонового круга в виджете подключения.
- Уточнены возможности Sentinel.
- Вставка SIP008 JSON напрямую с выбором серверов и проверкой формата.

Отмена обновления останавливает загрузку. Новый APK заменяет предыдущий только после проверки размера и хеша; временные файлы разных загрузок независимы.
После отмены обновления можно повторить загрузку; поздний ответ не заменяет новый результат. Некорректные имена APK отклоняются до доступа к файлам.
