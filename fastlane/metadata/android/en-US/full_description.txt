FoxHole Guard is a privacy and device-protection app for Android. It combines an encrypted VPN tunnel, Tor routing, a local firewall, DNS filtering, and on-device security monitoring in one app — with no ads, no analytics, and no telemetry.

It is more than a VPN client: the firewall, DNS protection, and Tor work even without a VPN profile, and every analysis runs locally on the device.

What it protects and how:

* Traffic privacy — the VPN tunnel encrypts device traffic and replaces your public IP address with the server address. Powered by the native Rust FoxCore runtime with strict TLS verification by default.
* Anonymity — Tor routing sends TCP traffic from selected apps, or the whole device, through the Tor network. Tor can run inside the VPN tunnel or on its own without any VPN profile.
* Network control — the local firewall blocks internet access for selected apps, keeps a connection journal, and feeds the live traffic map. It works with or without a VPN.
* DNS hygiene — the DNS filter blocks ads, trackers, telemetry, and malicious domains. System DNS protection works even without a VPN profile.
* Device security — the new app monitor shows where each installed app came from and flags risky capabilities. Quarantine blocks new apps from the network until you allow access. Anomaly analysis reports unusual traffic.

Typical scenarios:

* Everyday privacy — start the VPN and turn on the DNS filter: traffic is encrypted, ads and trackers are blocked.
* Maximum anonymity — start the VPN with a TCP protocol and turn on Tor routing for the apps that need it.
* Tor without VPN — start Tor with no VPN profile; TCP traffic from the selected scope goes through the Tor network.
* Protection without VPN — turn on the firewall and system DNS protection with no VPN profile at all.

Key features:

* VPN tunnel and local proxy modes
* split tunnel for apps and domains
* Tor routing for selected apps or the entire device (TCP)
* local firewall with per-app blocking and quarantine for new apps
* local DNS filtering with per-app and per-domain exceptions
* new app monitor with installer source and risk signals
* anomaly analysis of local traffic
* live traffic map with destination countries
* LAN proxy over Wi-Fi with proxy authentication
* domain-based routing rules
* profile import from files, QR codes, clipboard, and HTTPS subscriptions
* local traffic statistics and subscription expiration display
* encrypted local profile storage

Supported protocols: VLESS, Trojan, Shadowsocks, VMess, Hysteria2, WireGuard, Outline, Naive, TUIC, AnyTLS.

Smart Config can auto-connect to a suitable option from the available protocols. Selection is based on local history of successful and failed connections, latency, network state, and the last working option. This data is not sent to the developer or shared with third-party servers.

Tor network:
Only TCP traffic is sent through the Tor network; UDP stays on the regular VPN route or is blocked depending on settings. Tor is a trademark of The Tor Project. FoxHole Guard is not a product of The Tor Project and is not endorsed, sponsored, or affiliated with The Tor Project.

DNS filtering:
The beta uses a bundled filter based on AdGuard DNS. Its signed remote update channel is off by default and accepts only a compatible schema-2 manifest after signature, expiry, rollback, size and SHA-256 checks. Downloaded FoxCore filtering data is not executable code. If the channel is unavailable or verification fails, the bundled or last verified filter stays in use. FoxHole Guard is not a product of AdGuard and is not affiliated with AdGuard Software Ltd.

Permissions and privacy:
QUERY_ALL_PACKAGES is used to choose apps for VPN/proxy routing, firewall rules, DNS exceptions, the local installed-app overview, and optional per-app traffic statistics. PACKAGE_USAGE_STATS is requested only when per-app statistics are enabled. Package lists, local risk signals, statistics, diagnostics, auto-connect history, user DNS exceptions, and DNS filtering state stay on the device unless the user explicitly exports or sends them.

Network requests:
FoxHole Guard contains no ads, analytics, or telemetry. The app may make network requests for features selected by the user: loading HTTPS subscriptions, checking connection health, obtaining current IP address information through a configurable endpoint, operating the selected DNS server, and optionally downloading an updated DNS rule set. FoxHole Guard does not send the developer installed app lists, custom DNS exceptions, DNS logs, or DNS filtering statistics.
