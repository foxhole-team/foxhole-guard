Foxhole is an Android client for connecting to and managing sing-box profiles with support for a VPN tunnel, local proxy, split routing, and optional routing of selected apps' TCP traffic through the Tor network inside the VPN.

The app can run connections in VPN tunnel and local proxy modes, configure split routing for apps and domains, and use basic traffic restriction rules.

Key features:

* VPN tunnel and local proxy mode
* split routing for apps and domains
* optional TCP traffic routing through the Tor network
* LAN proxy over Wi-Fi
* proxy authentication
* domain-based routing rules
* profile import from files, QR codes, clipboard, and HTTPS subscriptions
* local traffic statistics
* subscription expiration display
* encrypted local profile storage

Supported protocols:

* VLESS
* Trojan
* Shadowsocks
* VMess
* Hysteria2
* WireGuard
* Outline


Smart start selects a suitable connection option from the available protocol options. Selection is based on local history of successful and failed connections, latency, network state, and the last working option. This data is not sent to the developer or shared with third-party servers.

Tor network:
The app includes optional TCP traffic routing through the Tor network. UDP traffic is not sent through the Tor network. If Tor routing is enabled inside the VPN, selected TCP traffic goes through the Tor network, while UDP traffic stays on the regular VPN route or is blocked depending on settings.

Permissions and privacy:
QUERY_ALL_PACKAGES is used to choose apps that are included in or excluded from VPN/proxy routing, for the local installed-app overview, and for optional per-app traffic statistics.
PACKAGE_USAGE_STATS is requested only when per-app statistics are enabled. Package lists, local risk signals, statistics, diagnostics, and Smart start history stay on the device unless the user explicitly exports or shares them.

Network requests:
Foxhole contains no ads, analytics, or telemetry. The app may make network requests for features selected by the user: loading HTTPS subscriptions, checking connection health, and getting current IP address information through a configurable endpoint. These requests are needed for VPN/proxy operation and connection validation.
