Foxhole is a simple Android client for connecting to and managing sing-box profiles.

It supports Tunnel, Split Tunnel (per-app and per-domain), Proxy, and LAN Proxy, along with profile import from files, clipboard, QR codes, and HTTPS subscriptions.

No ads. No analytics. No telemetry.

Key features:

* Modes: Tunnel, Split Tunnel, Proxy
* LAN Proxy over Wi-Fi for access from other devices
* Proxy authentication
* Domain-based routing rules
* Profile import: file, clipboard, QR code, HTTPS subscriptions
* Support for Foxhole Smart Config and automatic protocol selection (Smart start)
* Local traffic statistics
* Subscription expiration display
* Encrypted local profile storage

Smart start automatically selects the most reliable protocol by testing available options and using local history.
It takes into account connection success rate, latency, and recent failures. All processing is performed on-device.

Permission note:
Foxhole uses QUERY_ALL_PACKAGES to show installed apps for Split Tunnel include/exclude routing, local installed-app inventory/security review, and optional per-app traffic statistics. Usage Access (PACKAGE_USAGE_STATS) is requested only when per-app traffic statistics are enabled. Package lists, local risk signals, traffic statistics, diagnostics, and Smart start history stay on-device unless you explicitly export or share them.

Supported protocols:

* VLESS
* Trojan
* Shadowsocks
* VMess
* Hysteria2
* WireGuard
* Outline
