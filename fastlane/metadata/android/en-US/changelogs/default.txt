0.1.1 public beta — security and reliability fixes

- Adds a white accent, optional monochrome themes and launcher icon, and a shorter update notice.
- Updates FoxCore to 0.0.5 with fixes for live-connection revocation, concurrent policy updates, private DNS validation, and domain routing.
- Requires explicit consent for anonymous local proxies and authenticates notification commands before switching profiles.
- Keeps runtime state consistent during network handoffs and policy reloads.
- Isolates WebApp views, proxy sessions, and pending browsing-data deletion; refuses page loads when storage isolation fails.
- Rejects stale profile-editor updates and preserves concurrent protocol changes.
- Rebuilds I2P and Tor transports with updated OpenSSL, Go, and transport dependencies.
- Expands delivery inventory, vulnerability checks, release-signature verification, and Android regression coverage.
- Corrects directory syncing, WebApp route availability, and the F-Droid source-build recipe.
Build: fix license packaging for emulator ABIs.
CI: wait for Package Manager and stage device APKs before installation on API 37.
