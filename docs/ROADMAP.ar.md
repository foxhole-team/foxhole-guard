# خارطة الطريق

نعمل بنشاط على تطوير FoxHole Guard وتحسين تطبيق Android وFoxHole Core، ونعمل أيضًا على إصدار iOS وعملاء سطح المكتب.

FoxHole مشروع مستقل وغير تجاري ومفتوح المصدر، نطوّره ونصونه بوقتنا ومواردنا الخاصة. وبقدرات محدودة، نتقدم تدريجيًا ولا يمكننا الالتزام بمواعيد إصدار ثابتة لكل ميزة أو منصة. يظل الأمان والاستقرار وجودة الوظائف القائمة أولوياتنا.

تساعد المساهمات وتقارير الأخطاء والاختبارات والدعم المالي على دفع المشروع إلى الأمام.
